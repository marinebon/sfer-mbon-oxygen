Presence table: which stations, which cruises

Every cell is one station-cruise pair: filled if that station was occupied on that cruise. Stations (rows) are ordered by the cruise on which they first appear, so new stations entering the program show up as a new row starting partway across the plot — a staircase pattern reveals when the network expanded. Cruises (columns) run left to right in chronological order. Zoom and hover to identify a cell.
